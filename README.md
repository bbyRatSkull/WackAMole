Hi! This is the first pygame game I have ever made, so it's not perfect.
My ideal version of this game is not one that is currently published, but as it stands it is fully functional. 
All art is made by me and all music is from free to use platforms. 
Functionality: 
  a full game of whack-a-mole that tracks highscores on the user's computer
  4 powerups with their own unique functionalities
  a working shop with dialogue
  custom mallets as the cursor image
  a handmade animation that plays for the intro of the game
